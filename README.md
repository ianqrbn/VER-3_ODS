# VER-3_ODS

Componentes do pipeline de visão computacional para análise de conformidade de EPI.

- [I9](I9/) — verificador de EPI por pessoa: verificação **geométrica** (sem modelo
  de visão computacional) de uso `CORRETO` / `INCORRETO` / `AUSENTE` por pessoa,
  a partir do rastreio do I2 e da calibração do I3. A anatomia e sua geometria
  estão no motor; a aplicação configura apenas quais EPIs são obrigatórios e em
  qual zona. Ver [`I9/README.md`](I9/README.md).
